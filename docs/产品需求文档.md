# Plume——PostgreSQL 轻量可视化管理工具产品需求文档

> 文档版本：v0.4  
> 文档状态：MVP 已确认  
> 更新日期：2026-07-27  
> 产品名称：Plume

## 1. 文档目的

本文档定义一款轻量 PostgreSQL 桌面管理工具的产品目标、用户范围、核心流程、功能需求、质量要求和 MVP 验收标准，作为产品设计、交互设计、技术方案与开发排期的共同依据。

当前版本重点回答：首个可用版本为谁服务、解决什么问题、必须具备哪些能力，以及哪些内容暂不进入首版。

## 2. 产品概述

### 2.1 一句话定义

**Plume** 是一款打开即用、界面清爽、安全可靠，专注于 PostgreSQL 日常开发与数据操作的跨平台桌面工具。

### 2.2 产品形态

- 免费开源的桌面客户端，macOS 与 Windows 同步首发，Linux 视资源情况跟进。
- 应用直接连接用户指定的 PostgreSQL 实例。
- 不依赖厂商远程服务端，不要求注册和登录。
- 数据库凭据、查询历史、收藏 SQL 等信息默认只保存在本地。
- PostgreSQL 实例可位于本机、局域网、云服务或 SSH 隧道之后。

### 2.3 产品价值

- **更快开始：** 从启动应用到执行第一次查询所需步骤尽可能少。
- **更容易理解：** 核心信息层级清楚，非必要功能不长期占据界面。
- **更安全操作：** 对生产环境、批量修改和危险 SQL 提供明确保护。
- **更轻量运行：** 控制安装体积、启动时间和空闲资源占用。
- **更专注 PostgreSQL：** 优先做好 PostgreSQL 特性，而不是泛化支持多种数据库。

## 3. 背景与问题

现有数据库管理工具常见以下问题：

- 功能庞杂，首次使用学习成本高。
- 启动慢、安装包大、空闲资源占用明显。
- 对象树、工具栏和属性面板层级过深，视觉噪声较多。
- 查询、查看数据、修改记录等高频任务操作路径偏长。
- 开发、测试、生产环境区分不够醒目，存在误操作风险。
- 一些工具为了兼容多类数据库，未能充分适配 PostgreSQL 的对象与行为。

本产品不追求覆盖完整 DBA 工作，而是先优化开发者每天反复进行的连接、查找对象、运行 SQL、浏览数据和安全修改数据等任务。

## 4. 产品目标与成功指标

### 4.1 MVP 目标

1. 用户能够在 1 分钟内添加并成功连接一个 PostgreSQL 数据库。
2. 用户能够快速定位表、查看结构和浏览数据。
3. 用户能够顺畅编写、执行、取消 SQL，并理解执行结果或错误。
4. 用户能够安全地新增、修改和删除表数据。
5. 应用在常规数据库规模下保持快速启动与流畅交互。
6. 用户无需账号或远程服务即可使用全部 MVP 功能。

### 4.2 核心指标

北极星指标：**从启动应用到获得第一次查询结果的中位耗时。**

辅助指标：

| 指标 | MVP 目标 |
|---|---:|
| 冷启动时间 | 目标不高于 2 秒，最终以目标设备实测为准 |
| 新建连接完成率 | 不低于 95%（配置有效的前提下） |
| 首次连接操作时长 | 80% 用户可在 1 分钟内完成 |
| 打开表数据首屏时间 | 常规网络下目标不高于 2 秒 |
| SQL 执行状态反馈 | 发起执行后 100 毫秒内出现运行状态 |
| 默认单次数据加载量 | 200 行，可配置 |
| 严重误操作 | 产品自身缺陷导致的数据误修改为 0 |

说明：安装包体积、内存占用等数值需在技术验证后确定，不在需求阶段承诺未经验证的硬指标。

## 5. 目标用户

### 5.1 核心用户

**后端或全栈开发者**

- 高频连接开发、测试数据库。
- 需要编写 SQL、排查数据、查看表结构和少量修改数据。
- 熟悉基础 SQL，但不希望配置复杂数据库工具。

**独立开发者与小团队成员**

- 希望一个工具完成大部分 PostgreSQL 日常操作。
- 对免费、本地优先、安装简单和低资源占用比较敏感。

### 5.2 次要用户

- 测试人员：查询、构造和校验测试数据。
- 产品或数据人员：在只读或受控连接中查看数据和导出结果。
- 运维人员：执行临时查询、查看对象和基础会话信息。

### 5.3 非目标用户

MVP 不以需要完整监控、备份调度、集群运维、审计平台或复杂权限治理的专业 DBA 团队为主要用户。

## 6. 设计原则

1. **默认简单：** 首屏只呈现高频功能，高级选项按需展开。
2. **信息优先：** 数据和 SQL 是界面主角，装饰元素保持克制。
3. **渐进披露：** 不要求用户一次理解所有数据库对象和配置项。
4. **状态明确：** 当前连接、数据库、Schema、执行状态和未提交修改始终可识别。
5. **安全默认：** 生产环境和危险操作的默认策略偏向谨慎。
6. **键鼠兼容：** 新用户可依赖鼠标，熟练用户可使用键盘完成高频任务。
7. **大数据友好：** 对象元数据按需读取，结果集分页或流式处理。
8. **本地优先：** 没有明确授权时，不向外部服务发送连接信息、SQL 或数据。

## 7. 产品范围

### 7.1 MVP 范围

- PostgreSQL 连接管理。
- SSL 连接与 SSH Tunnel。
- 数据库对象导航与搜索。
- 表结构、约束、索引和 DDL 查看。
- 表数据浏览、筛选、排序和分页。
- 受控的数据新增、编辑与删除。
- SQL 编辑、自动补全、执行、取消和结果展示。
- 查询历史与收藏 SQL。
- 查询结果导出 CSV、JSON。
- 基础 `EXPLAIN` 与 `EXPLAIN ANALYZE`。
- 本地设置、主题和快捷键。

### 7.2 MVP 暂不包含

- MySQL、SQLite、SQL Server 等其他数据库支持。
- 云端账号、跨设备同步和团队协作。
- 数据库监控告警平台。
- 定时备份、恢复和任务调度。
- 可视化 ER 图编辑器。
- 数据库迁移、Schema Diff 与版本管理。
- 完整角色、权限和行级安全策略管理。
- AI 自动生成或自动执行 SQL。
- 插件市场。
- PostgreSQL 服务端安装、升级和集群运维。
- AWS、Azure、GCP 等云数据库 IAM 临时认证。

## 8. 信息架构与主界面

### 8.1 主界面结构

```text
┌────────────────────────────────────────────────────────────┐
│ 连接切换 / 全局搜索 / 新建查询 / 当前环境                  │
├──────────────┬──────────────────────────────┬──────────────┤
│ 对象导航     │ 主工作区                     │ 详情面板     │
│              │ SQL / 数据 / 结构            │ 可收起       │
├──────────────┴──────────────────────────────┴──────────────┤
│ 连接状态 / 查询状态 / 执行耗时 / 返回或影响行数            │
└────────────────────────────────────────────────────────────┘
```

### 8.2 对象树

```text
服务器连接
├── Databases
│   └── Database
│       ├── Casts
│       ├── Catalogs
│       ├── Event Triggers
│       ├── Extensions
│       ├── Foreign Data Wrappers
│       ├── Languages
│       ├── Publications
│       ├── Schemas
│       │   └── Schema
│       │       ├── Tables
│       │       ├── Foreign Tables
│       │       ├── Views
│       │       ├── Materialized Views
│       │       ├── Sequences
│       │       ├── Functions
│       │       ├── Procedures
│       │       └── Types
│       └── Subscriptions
├── Login/Group Roles
└── Tablespaces
```

对象导航遵循 PostgreSQL/pgAdmin 的服务器、数据库、Schema 层级。对象节点按需加载，不在连接成功后一次性读取所有元数据；同一服务器下的其他数据库在首次展开时按需建立独立数据库会话。

### 8.3 标签页类型

- SQL 查询页。
- 表数据页。
- 表结构页。
- View 或 Function 定义页。
- 执行计划页。

应用退出后可恢复上次打开的标签页，但不得自动重新执行 SQL。

## 9. 核心用户流程

### 9.1 首次连接并查询

1. 用户启动应用。
2. 点击“新建连接”。
3. 输入连接参数或粘贴 PostgreSQL URL。
4. 点击“测试连接”。
5. 保存并连接。
6. 通过对象树选择表，或创建 SQL 查询页。
7. 执行查询并查看结果。

### 9.2 浏览并修改一条数据

1. 用户双击一张表，打开数据页。
2. 应用加载首批数据。
3. 用户筛选或定位目标记录。
4. 用户编辑单元格。
5. 应用标记未提交变更并展示变更摘要。
6. 用户确认提交或放弃变更。
7. 应用反馈成功状态；失败时保留变更并显示原因。

### 9.3 执行危险 SQL

1. 用户在 SQL 编辑器发起执行。
2. 应用识别明显的高风险语句。
3. 确认窗口展示连接环境、数据库、Schema 与风险摘要。
4. 用户明确确认后执行，或取消返回编辑器。

风险检测用于辅助防错，不承诺代替数据库权限、事务和备份策略。

## 10. 功能需求

优先级定义：P0 为 MVP 必须完成；P1 为强烈建议随 MVP 完成；P2 可在后续版本实现。

### 10.1 连接管理

#### FR-CONN-001 新建连接（P0）

用户可通过表单创建 PostgreSQL 连接，字段至少包含：

- 连接名称。
- Host。
- Port，默认 5432。
- Database。
- Username。
- Password。
- 环境类型：开发、测试、预发布、生产、自定义。
- 连接颜色。

**验收标准：**

- 必填项缺失时阻止提交，并在对应字段附近提示。
- 密码输入默认不可见，可临时切换显示。
- 连接成功后进入对应数据库工作区。
- 连接失败时展示可理解的原因，不只显示底层错误码。

#### FR-CONN-002 URL 导入（P0）

用户可粘贴 `postgres://` 或 `postgresql://` URL，应用解析并填充连接表单。

**验收标准：** URL 中的特殊字符、SSL 参数能够正确解析；解析前不会自动发起连接。

#### FR-CONN-003 测试连接（P0）

用户可在保存前测试连接。

**验收标准：** 显示成功耗时，或按网络、认证、数据库不存在、SSL 等类别提示失败原因。

#### FR-CONN-004 保存与管理连接（P0）

用户可收藏、编辑、复制、重命名和删除本地连接配置。

**验收标准：** 删除连接前确认；删除连接配置不会对远程数据库执行任何操作。

#### FR-CONN-005 凭据安全存储（P0）

密码默认存入操作系统安全凭据设施；普通配置文件只保存非敏感字段和凭据引用。

#### FR-CONN-006 SSL（P0）

至少支持 PostgreSQL 常见 SSL 模式：disable、prefer、require、verify-ca、verify-full，并允许选择 CA、客户端证书和私钥。

#### FR-CONN-007 SSH Tunnel（P0）

支持密码或私钥方式建立 SSH Tunnel，并允许配置跳板机地址、端口和用户名。

#### FR-CONN-008 只读模式（P1）

连接可被标记为只读。只读模式下，数据编辑入口禁用，并拦截应用能够识别的写操作；数据库自身权限仍是最终保障。

#### FR-CONN-009 连接状态与重连（P0）

界面持续展示连接中、已连接、繁忙、已断开等状态。因网络问题断开时允许用户主动重连，不应静默重复执行未完成的写操作。

### 10.2 对象导航与搜索

#### FR-OBJ-001 对象树（P0）

按服务器、数据库、数据库级对象、Schema 和 Schema 对象类型分组展示，节点展开时按需加载。服务器级至少包含 Databases、Login/Group Roles、Tablespaces；数据库级至少包含 Casts、Catalogs、Event Triggers、Extensions、Foreign Data Wrappers、Languages、Publications、Schemas、Subscriptions。

#### FR-OBJ-002 对象搜索（P0）

用户可按名称模糊搜索表、View、Function 等对象，并从结果直接打开。

**验收标准：** 支持键盘选择与打开；结果展示对象类型和所属 Schema。

#### FR-OBJ-003 刷新（P0）

用户可刷新单个节点、Schema 或整个连接，而不强制关闭当前工作页。

#### FR-OBJ-004 快捷操作（P0）

对象菜单至少支持：打开数据、打开结构、新建关联查询、复制名称、复制限定名称、查看 DDL。

#### FR-OBJ-005 标识符处理（P0）

复制和生成 SQL 时正确处理大小写、保留字及包含特殊字符的 PostgreSQL 标识符。

### 10.3 表结构查看

#### FR-STRUCT-001 字段信息（P0）

展示字段名称、类型、是否可空、默认值、注释和序号。

#### FR-STRUCT-002 约束与索引（P0）

展示主键、唯一约束、外键、Check 约束和索引，包括涉及字段和定义。

#### FR-STRUCT-003 DDL 查看（P0）

用户可查看并复制应用生成的对象 DDL。界面需说明生成结果可能与原始建表文本格式不同。

#### FR-STRUCT-004 结构修改（P2）

可视化新增、修改、删除字段和索引不纳入首个 MVP；首版通过生成或手写 SQL 完成结构变更。

### 10.4 表数据浏览

#### FR-DATA-001 打开表数据（P0）

双击表默认打开数据页，首批默认读取 200 行，不执行全表一次性加载。

#### FR-DATA-002 分页（P0）

支持上一页、下一页和修改每页行数。对于无法稳定排序的数据，提示分页结果可能变化。

#### FR-DATA-003 排序（P0）

支持对一个或多个字段升序或降序排列，并清楚展示当前排序条件。

#### FR-DATA-004 筛选（P0）

提供可视化条件筛选，至少支持等于、不等于、包含、大于、小于、为空和非空；同时可查看生成的条件表达式。

#### FR-DATA-005 单元格展示（P0）

明确区分 `NULL`、空字符串、空白字符、布尔值、二进制内容和截断的长文本。

#### FR-DATA-006 列操作（P1）

支持调整列宽、固定列、隐藏列、复制单元格、复制整行和复制为 SQL/JSON。

#### FR-DATA-007 大字段（P1）

长文本、JSON、数组和二进制内容使用独立查看器打开；表格中只展示安全长度的预览，避免阻塞渲染。

### 10.5 数据编辑

#### FR-EDIT-001 可编辑性判断（P0）

应用仅在能够可靠定位单行时启用表格编辑，优先使用主键或非空唯一键。无法可靠定位时进入只读浏览状态并说明原因。

#### FR-EDIT-002 修改记录（P0）

用户修改单元格后，界面显示原值、新值和未提交状态。修改不会因切换单元格而立即写入数据库。

#### FR-EDIT-003 新增记录（P0）

用户可新增一行，未填写字段遵循 NULL 或数据库默认值语义，不擅自以空字符串替代。

#### FR-EDIT-004 删除记录（P0）

删除操作先进入待提交状态；提交前展示将删除的行数和用于定位记录的键值。

#### FR-EDIT-005 批量提交或放弃（P0）

用户可一次提交当前数据页的全部变更，或全部放弃。提交应在事务中执行；任一操作失败时默认回滚整批变更。

#### FR-EDIT-006 并发冲突（P1）

当记录在编辑期间已被其他会话修改或删除时，应用不得静默覆盖，应提示冲突并允许刷新后重新处理。

#### FR-EDIT-007 离开保护（P0）

存在未提交修改时，关闭标签、断开连接或退出应用必须提示用户提交、放弃或取消离开。

### 10.6 SQL 编辑器

#### FR-SQL-001 编辑体验（P0）

支持 PostgreSQL SQL 语法高亮、括号匹配、自动缩进、行号、查找替换和基础格式化。

#### FR-SQL-002 自动补全（P0）

根据当前连接上下文补全 Schema、表、字段、View 和常见 PostgreSQL 关键字或函数。元数据读取不得阻塞输入。

#### FR-SQL-003 执行范围（P0）

支持执行选中 SQL、光标所在语句和编辑器全部内容。默认规则需在按钮提示和快捷键说明中保持一致。

#### FR-SQL-004 执行反馈（P0）

执行期间展示运行状态、已用时间和取消按钮；完成后展示耗时、返回行数或影响行数。

#### FR-SQL-005 取消查询（P0）

用户可请求取消正在执行的查询。取消后明确展示取消结果；若服务端尚未确认取消，不得伪装为已取消。

#### FR-SQL-006 多结果集（P1）

一次执行包含多条语句时，分别展示每条语句的结果或状态，并能定位错误语句。

#### FR-SQL-007 错误提示（P0）

显示 PostgreSQL 返回的错误消息、错误位置和可用详细信息；错误内容支持复制，但日志需隐藏敏感字段。

#### FR-SQL-008 标签页（P0）

支持多个查询标签页、重命名和未保存标记。应用意外退出后恢复编辑内容，但不自动执行。

#### FR-SQL-009 查询历史（P0）

在本地记录执行时间、连接标识、SQL、耗时和结果状态。用户可搜索、重新打开、复制和清空历史。历史默认保留 90 天且最多保存 10,000 条；任一上限触发后按执行时间自动清理最旧记录。用户可调整保留期限和数量上限。

#### FR-SQL-010 收藏 SQL（P1）

用户可保存常用 SQL，并为其设置名称和可选标签。收藏默认只保存在本机。

#### FR-SQL-011 事务控制（P1）

默认使用自动提交；允许切换手动事务模式，并持续显示事务状态。存在未提交事务时，关闭标签或断开连接必须提示。

### 10.7 查询结果

#### FR-RESULT-001 表格结果（P0）

查询结果以虚拟化表格展示，支持调整列宽、复制单元格或行、NULL 区分和长内容查看。

#### FR-RESULT-002 结果限制（P0）

应用提供默认结果行数限制，并明确提示结果是否被截断。不得通过简单改写 SQL 破坏用户原查询语义。

#### FR-RESULT-003 多视图（P1）

单条记录可切换为纵向详情视图；JSON 数据可格式化或以树状查看。

#### FR-RESULT-004 导出（P0）

支持将当前结果导出为 CSV 或 JSON，可选择全部已获取结果或选中行。

**验收标准：**

- CSV 可设置分隔符、编码和是否包含表头。
- 导出过程中显示进度并允许取消。
- 导出失败不产生看似完整的最终文件；临时文件应被安全处理。

### 10.8 执行计划

#### FR-PLAN-001 EXPLAIN（P1）

用户可对适用 SQL 执行 `EXPLAIN`，并查看文本或结构化计划。

#### FR-PLAN-002 EXPLAIN ANALYZE 风险提示（P1）

执行 `EXPLAIN ANALYZE` 前明确说明 SQL 会被真实执行，写操作可能修改数据；确认信息需展示当前环境和数据库。

### 10.9 安全与风险保护

#### FR-SAFE-001 环境识别（P0）

用户可为连接设置环境类型和颜色。生产环境颜色持续出现在顶部连接区域、标签页或状态栏中。

#### FR-SAFE-002 危险 SQL 提示（P0）

对应用能够识别的 `DROP`、`TRUNCATE`、无条件 `DELETE`、无条件 `UPDATE` 等高风险语句，在执行前显示确认。

确认信息至少包含：

- 连接名称和环境。
- Host、Database 和当前 Schema。
- 即将执行的语句摘要。
- 风险类型。

#### FR-SAFE-003 生产环境强化（P1）

危险 SQL 提示可按连接配置关闭或调整，但生产环境连接不得完全关闭保护。生产连接对结构删除、清空表等操作采用强化确认，例如要求输入数据库名后才能执行；产品不提供全局静默关闭全部保护的能力。

#### FR-SAFE-004 敏感信息保护（P0）

应用日志、错误上报和界面通知不得暴露密码、私钥内容或完整含密连接 URL。

#### FR-SAFE-005 运行超时（P1）

允许设置连接超时和查询超时。超时后提示实际状态，不能假定数据库事务一定已经回滚。

### 10.10 设置与桌面体验

#### FR-SET-001 外观（P1）

支持浅色、深色和跟随系统；提供普通与紧凑两档信息密度。

#### FR-SET-002 快捷键（P0）

至少提供以下默认快捷键，并适配不同操作系统：

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 执行当前或选中 SQL | `Cmd + Enter` | `Ctrl + Enter` |
| 新建查询 | `Cmd + N` | `Ctrl + N` |
| 全局搜索/命令面板 | `Cmd + K` | `Ctrl + K` |
| 查找对象 | `Cmd + P` | `Ctrl + P` |
| 保存 SQL | `Cmd + S` | `Ctrl + S` |
| 关闭标签 | `Cmd + W` | `Ctrl + W` |

#### FR-SET-003 会话恢复（P1）

恢复窗口布局、已打开标签和未保存 SQL。连接是否自动重连由用户设置决定，写操作和查询不得自动重放。

#### FR-SET-004 更新（P2）

支持检查新版本和可选自动更新。更新机制不得发送数据库连接信息或使用行为内容。

## 11. 非功能需求

### 11.1 性能

- 应用启动过程不得等待数据库自动连接完成后才显示主界面。
- 对象树采用懒加载，并缓存必要元数据。
- 数据表和结果表格使用虚拟化渲染，避免 DOM 节点随结果行数无限增长。
- 数据库查询、导出和元数据读取均不得阻塞 UI 主线程。
- 大结果集采用分页、游标或流式读取；不得默认将全量结果放入内存。
- 单个查询卡顿不得导致其他标签页和取消按钮失去响应。

### 11.2 稳定性

- 应用崩溃或非正常退出后尽可能恢复未保存 SQL。
- 网络中断后保留编辑器内容和已展示结果，不自动重放写操作。
- 数据编辑的批量提交在单一事务中完成，失败默认全部回滚。
- 关键本地配置采用安全写入策略，避免中途退出导致配置文件整体损坏。

### 11.3 安全与隐私

- 默认不采集 SQL 文本、查询结果、连接地址或数据库结构。
- 若未来加入诊断数据上报，必须默认匿名、清楚说明内容并允许关闭。
- 密码使用系统凭据存储；私钥文件不复制到应用普通数据目录。
- 应用内部的本地核心不开放不必要的网络监听端口。
- 前端界面不长期持有明文密码；本地核心仅在建立连接所需期间读取凭据。
- 导出的数据文件由用户明确选择路径，应用不擅自上传。

### 11.4 兼容性

- MVP 支持 PostgreSQL 14 及以上版本；各版本的具体兼容性需通过自动化测试矩阵验证。
- macOS 13+ 与 Windows 10/11 同步首发。
- Linux 支持进入候选范围，需单独验证系统凭据、WebView 和发行包兼容性。
- 支持高分屏和系统缩放；简体中文与英文界面随 MVP 同步发布。

### 11.5 可访问性

- 主要功能可使用键盘操作。
- 焦点状态清楚可见。
- 文字与背景对比度满足 WCAG AA 的基本要求。
- 风险状态不能只通过颜色表达，需同时使用文字或图标。

### 11.6 可维护性

- UI 层与数据库核心通过受控 IPC 接口通信，不允许 UI 任意调用系统命令。
- 查询、连接、元数据、导出和凭据模块职责分离。
- 数据库驱动错误统一转换为面向用户的错误结构，同时保留可复制的技术详情。

## 12. 本地数据与隐私边界

### 12.1 本地保存内容

- 非敏感连接配置。
- 系统凭据引用。
- 用户设置与窗口布局。
- 查询历史。
- 收藏 SQL。
- 未保存编辑器草稿。
- 必要的对象元数据缓存。

### 12.2 默认不保存内容

- 查询结果全集。
- 明文密码。
- SSH 私钥内容。
- 用户未明确导出的数据库数据。

### 12.3 清理能力

用户可分别清理查询历史、草稿、缓存和全部本地数据。删除连接时，可选择是否同时删除系统凭据。

## 13. 错误与边界场景

MVP 必须覆盖以下情况：

- Host 无法访问、DNS 失败或连接超时。
- 用户名或密码错误。
- 数据库不存在或用户无连接权限。
- SSL 证书错误或主机名不匹配。
- SSH Tunnel 创建失败或中途断开。
- 查询执行中网络断开。
- 用户请求取消，但数据库未及时确认。
- 结果包含超长文本、JSON、数组、二进制和无法直接显示的类型。
- 表没有主键或可靠唯一键。
- 用户编辑期间数据被其他会话修改。
- 导出目标无写权限或磁盘空间不足。
- 应用退出时存在未保存 SQL、未提交数据或未提交事务。

## 14. MVP 验收场景

### AC-01 新建连接

在全新安装状态下，用户可以通过表单或 URL 创建连接、测试连接并进入数据库工作区；密码不出现在普通配置文件中。

### AC-02 浏览数据库对象

用户可以展开 Schema、搜索一张表并查看字段、约束、索引和 DDL；大型数据库下不会在连接阶段一次性加载全部对象。

### AC-03 浏览表数据

用户双击表后能看到首批数据，进行筛选、排序和翻页；界面明确区分 NULL 和空字符串。

### AC-04 安全修改数据

对具有主键的表，用户能够新增、修改和删除记录，提交前查看变更，失败时整批回滚；无可靠唯一键的表默认不可直接编辑。

### AC-05 编写与执行 SQL

用户可以获得基础自动补全，执行选中或当前语句，查看结果、耗时和影响行数，并取消长时间查询。

### AC-06 错误处理

错误 SQL 能定位到相关位置并展示 PostgreSQL 错误详情；网络、认证和权限错误具有可理解的分类提示。

### AC-07 防止误操作

生产连接具有持续可见的环境标识；执行识别出的高风险语句前展示数据库身份和风险确认。

### AC-08 导出结果

用户可以将查询结果导出为 CSV 或 JSON，导出期间可查看进度并取消，失败时不会遗留看似成功的完整文件。

### AC-09 会话恢复

应用非正常退出后可恢复未保存 SQL 和标签信息，但不会自动重新执行查询或写操作。

### AC-10 本地优先

断开互联网但能够访问目标 PostgreSQL 时，除更新检查等非核心能力外，所有 MVP 核心功能均可使用。

## 15. 建议迭代计划

详细工程任务、依赖关系与发布门槛见 [开发任务分解](./开发任务分解.md)。

### 阶段 A：技术验证

- 验证 Tauri、Rust PostgreSQL 驱动和前端表格方案。
- 验证查询取消、结果流、SSH、SSL、系统凭据和跨平台打包。
- 建立启动时间、内存和大结果集性能基线。

### 阶段 B：核心可用版本

- 连接管理。
- 对象树与搜索。
- SQL 编辑和执行。
- 查询结果表格。
- 表数据只读浏览。

### 阶段 C：MVP 完整版本

- 数据编辑与事务提交。
- 查询历史与收藏。
- CSV、JSON 导出。
- SSH、SSL 完整配置。
- 环境标识与危险操作保护。
- 会话恢复与稳定性完善。

### 阶段 D：体验优化

- 自动补全和命令面板优化。
- 执行计划可视化。
- 大型 Schema 和大结果集性能优化。
- Linux 兼容性评估。

## 16. 已确认产品决策

以下决策于 2026-07-27 确认，作为 MVP 设计、开发与验收基线：

| 编号 | 决策 | 对 MVP 的影响 |
|---|---|---|
| DEC-001 | macOS 与 Windows 同步首发 | 两个平台从技术验证阶段开始并行验证和打包，不以单一平台版本代替 MVP 交付 |
| DEC-002 | 产品免费开源 | 代码仓库、依赖许可和发布流程按开源产品管理；具体开源许可证另行确定 |
| DEC-003 | SSH Tunnel 纳入 MVP | SSH Tunnel 调整为 P0，必须进入首发验收范围 |
| DEC-004 | 简体中文与英文同步首发 | 所有界面文本从开发初期进入国际化资源，不允许把文案硬编码为单一语言 |
| DEC-005 | 查询历史默认保留 90 天或最多 10,000 条 | 任一上限触发后自动清理最旧记录，同时保留手动清理和自定义上限能力 |
| DEC-006 | 危险 SQL 提示可按连接配置，生产环境不可完全关闭 | 非生产连接允许按需调整；生产连接始终保留最低限度的强制保护 |
| DEC-007 | 最低支持 PostgreSQL 14 | 功能实现和测试矩阵以 PostgreSQL 14+ 为兼容边界 |
| DEC-008 | IAM 临时认证不纳入 MVP | 首版聚焦常规凭据、SSL 和 SSH；AWS、Azure、GCP IAM 认证进入后续候选范围 |
| DEC-009 | 产品正式命名为 Plume | 产品界面、安装包、代码仓库和发布物统一使用 Plume；对外说明可使用 `Plume - A clean PostgreSQL workspace` |
| DEC-010 | 对象导航采用 pgAdmin 风格的 PostgreSQL 完整层级 | 从服务器节点展示数据库、角色、表空间及数据库级对象分类，Schema 只是其中一个分支；所有层级保持按需加载 |

## 17. 产品底线

- 不因追求轻量而牺牲凭据安全和数据修改可靠性。
- 不把本地桌面核心包装成必须联网的远程服务。
- 不在未提示的情况下执行、重试或重放写操作。
- 不默认拉取整表或把无限结果集全部放入内存。
- 不为了兼容其他数据库而削弱 PostgreSQL 的核心体验。
