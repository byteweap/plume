# MVP 验收测试矩阵

P0-J03 使用分层端到端策略。`npm run test:acceptance` 驱动真实 React 应用和组件，从用户交互覆盖到 IPC API 边界；`npm run test:postgres` 在 PostgreSQL 14、16、18 上覆盖真实数据库、TLS 和 SSH 行为；Rust 单元测试覆盖本地存储、凭据边界和失败回滚。验收套件不访问互联网，也不会在开发机上保存真实凭据或导出文件。

## 场景覆盖

| 场景 | 自动化关键路径 | 后端与边界补充 |
|---|---|---|
| AC-01 新建连接 | 表单保存连接后才建立会话，测试覆盖 URL 导入与连接结果 | 系统凭据测试保证密码不进入 SQLite；PostgreSQL 矩阵验证真实连接 |
| AC-02 浏览数据库对象 | 逐级展开服务器、数据库、Schema 和表，断言每层按需加载 | PostgreSQL 矩阵验证系统目录、对象类型和可靠键元数据 |
| AC-03 浏览表数据 | 双击表后限制首批行数，并覆盖分页、排序、参数化筛选和 NULL 展示 | PostgreSQL 矩阵验证批次、结果上限与类型文本传输 |
| AC-04 安全修改数据 | 暂存新增记录、离开保护、提交失败保留变更、重试成功后刷新 | PostgreSQL 矩阵验证混合变更原子提交与任一行失败时整批回滚 |
| AC-05 编写与执行 SQL | 覆盖目录自动补全、当前语句/全部 SQL 执行和连接所有权 | PostgreSQL 矩阵验证多语句、参数查询、取消与结果计数 |
| AC-06 错误处理 | 错误 SQL 展示结构化诊断和位置，同时保持健康会话可用 | PostgreSQL 矩阵验证 SQLSTATE、severity、hint 和 position |
| AC-07 防止误操作 | 环境标识持续可见；生产高危 SQL 要求输入准确数据库名 | 风险识别单元基线覆盖高风险语句分类和策略过滤 |
| AC-08 导出结果 | 覆盖 CSV 选区与选项、JSON 全量结果、进度和取消 | Rust 导出测试验证原子替换、取消及失败时清理临时文件 |
| AC-09 会话恢复 | 恢复标签、名称和未保存 SQL，但不自动重连或重放查询 | Rust 工作区测试验证快照排除结果、会话、事务和凭据 |
| AC-10 本地优先 | 断开会话后保留可编辑草稿，并提供本地 SQL 关键字/函数补全 | 核心路径不包含外部网络 API；数据库能力只依赖目标 PostgreSQL |

## 运行方式

```bash
npm run test:acceptance
```

提交前的 `npm run check` 会自动运行该套件。涉及数据库行为的改动还应依次运行：

```bash
npm run postgres:up
npm run test:postgres
npm run postgres:down
```
